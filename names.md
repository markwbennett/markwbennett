# Tech-flavored names for a criminal-defense practice

Brainstorm in the spirit of *freedomlabs* / *libertyresearch*: legal-mechanism words
welded to software-company suffixes (labs, works, stack, forge, kernel, systems,
engine, foundry, research).

## How to read the "screen" column

I could not run WHOIS or RDAP from the session this was written in (outbound network
was restricted to GitHub), so **nothing here is a verified registration check**. The
screen column reports only what a web search turned up:

- **clear** — no company, product, or project found using the name
- **occupied** — someone is already trading under the name (skip it, or expect a fight)
- **unscreened** — not searched; assume a short two-word `.com` is registered until proven otherwise

Verify anything you like at a registrar, or locally with `whois name.com` /
`curl https://rdap.org/domain/name.com` (404 there means unregistered).

## Shortlist

If I had to pick five to check at a registrar first, in order:

1. **exculpo.com** — one word, coined-sounding, means exactly what the practice does, and turned up no commercial occupant at all.
2. **writforge.com** — concrete, craft-flavored, no occupant found; "we forge writs" is a real description of post-conviction work.
3. **reasonabledoubtlabs.com** — long, but the phrase is the product, and it screened clear.
4. **acquitlabs.com** — shortest clean hit in the acquittal family.
5. **voirdirelabs.com** — memorable to lawyers, opaque to everyone else; the full phrase screened clear.

## Caveat worth pricing in

Assuming Texas (inferred from the repo name and README naming Mark W. Bennett,
plus my general background knowledge that you practice criminal defense in
Texas — correct me if that's wrong): trade names are allowed. Rule 7.01 of the
Texas Disciplinary Rules of Professional Conduct was rewritten in the amendments
the Texas Supreme Court approved July 1, 2021, and is now titled "Communications
Concerning a Lawyer's Services"; it bars false or misleading communications about
a lawyer's or firm's services and permits a trade name that is not false or
misleading. That replaced the old 7.01 ("Firm Names and Letterhead"), which had
flatly barred practicing under a trade name — so any advice you find predating
mid-2021 is stale on this point.

I confirmed that via web search summaries of the State Bar's rule text rather
than the rule text itself (this session could not reach texasbar.com), so read
the current Rule 7.01 and the advertising-review materials directly before
committing.

The live question for these names is the "not misleading" half: a name like
*Exculpo* or *Writ Forge* is a coined mark and fine, but anything that implies a
capability you don't have — *Labs* suggesting an actual forensic laboratory, or a
name promising outcomes — is where the rule bites.
